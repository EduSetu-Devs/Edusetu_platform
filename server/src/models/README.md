# Models Directory

This directory will contain Mongoose schemas and data models for EduSetu:

- `User.js` - Base user model (Admin, Teacher, Student, Parent)
- `Class.js` - Class, section, and subject management
- `Notice.js` - School and classroom announcements
- `Message.js` - Direct and group communications
- `Attendance.js` - Daily student attendance tracking
- `Assignment.js` - Homework and study tasks

> *Note: Database models will be implemented in the next step according to project roadmap.*
